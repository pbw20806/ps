# 당신을 두 번 살렸습니다

4인 머더 미스터리의 **온라인 대기방·캐릭터 선택 프로토타입**입니다.
Godot **4.6.3 Standard**에서 검증했습니다. 별도 플러그인이나 유료 서비스는 필요 없습니다.

## 실행

1. 이 폴더 전체를 내려받습니다. 압축 파일이라면 먼저 압축을 풉니다.
2. Godot 프로젝트 관리자에서 **가져오기 → `project.godot`**을 선택합니다.
3. 프로젝트를 열고 최초 이미지·폰트 가져오기가 끝날 때까지 기다립니다.
4. **F5**로 실행합니다.

### 네 명이 플레이하기

1. 한 명이 **플레이 → 이름 입력 → 방 만들기**를 누릅니다.
2. 나머지 세 명은 **플레이 → 이름과 방장 IP 입력 → 주소로 참가**를 누릅니다.
3. 방장을 포함해 정확히 네 명이 접속하면 방장의 **게임 시작** 버튼이 활성화됩니다.
4. 각자 초상화를 보고 캐릭터를 선택한 뒤 **내 캐릭터 확정**을 누릅니다.
5. 먼저 선택한 사람에게 배정됩니다. 확정 전에는 다른 빈 캐릭터로 바꿀 수 있습니다.
6. 확정 후 바꾸려면 **확정 취소**를 누릅니다. 전원 확정 즉시 배역 소개 화면으로 이동합니다.
7. 방장은 배역 소개에서 대기방으로 돌아가 다시 배정할 수 있습니다.

### 혼자 네 창으로 확인하기

Godot 에디터의 다중 인스턴스 실행 기능으로 네 창을 실행하거나, 터미널 네 개에서 각각 다음을 실행합니다.

```sh
godot --path /path/to/ps
```

첫 창에서 방을 만들고 나머지 창에서는 `127.0.0.1`로 참가합니다. 각 창에 다른 이름을 입력하면 구분하기 쉽습니다. `godot` 명령이 등록되어 있지 않으면 Godot 실행 파일의 전체 경로로 바꾸세요.

### 서로 다른 컴퓨터에서 접속하기

- 같은 공유기: 방장 PC의 **사설 IPv4 주소**를 입력합니다.
- 다른 인터넷: 방장 공유기에서 선택한 **UDP 포트(기본 24567)**를 방장 PC로 포워딩하고, 참가자는 방장의 공인 주소로 접속합니다. PC 방화벽에서도 해당 연결을 허용해야 합니다.
- 통신사 CGNAT 등으로 포워딩이 불가능하면 별도의 VPN/LAN 연결 또는 추후 중계 서버가 필요합니다.
- 이 버전에는 방 코드, 공용 방 목록, 자동 NAT 통과, 상시 전용 서버가 없습니다. 방장 게임이 계속 실행되어 있어야 합니다.
- 포트가 사용 중이면 다른 포트를 정하고 네 사람 모두 같은 번호를 입력합니다.

## 구현 범위

- 만화풍 저택 배경과 네 용의자 초상화
- 메인 화면: 플레이 / 설정 / 게임 종료
- 설정: 전체 음량(버튼 효과음), 전체 화면, 로컬 저장
- ENet 기반 4인 대기방, 이름·인원 동기화, 네 명일 때만 시작
- 서버에서 검증하는 중복 없는 캐릭터 선택·변경·확정·취소
- 전원 확정 시 각자 선택한 배역 소개
- 참가자 이탈 시 선택 초기화 및 대기방 복귀, 다시 참가 가능
- 방장 종료·접속 실패·10초 연결 시간 초과 안내

**사건을 끝까지 진행하는 게임은 아직 아닙니다.** 비공개 역할지, 이동·단서 조사, 공간별 음성채팅, 토론·투표는 구현 전입니다. 배역 선택 화면에는 공개 소개만 있으며 범인이나 개인 비밀이 노출되지 않습니다.

## 파일 구조

- `project.godot`: 프로젝트 설정과 Lobby 자동 로드
- `scenes/main.tscn`: 메인 씬
- `scripts/main.gd`: 한국어 UI와 설정
- `scripts/lobby.gd`: 서버 권한을 기준으로 한 대기방·배역 상태 관리
- `assets/suspects.png`: 네 초상화가 나란히 담긴 원본. `AtlasTexture`로 각각 표시
- `assets/study.png`: 메인 배경
- `assets/Korean.otf`: Noto Sans CJK KR 서브셋. 라이선스는 `assets/FONT_LICENSE.txt`
- `assets/click.wav`: 합성 버튼 효과음
- `tests/`: 실제 네 프로세스 네트워크 테스트와 화면 구성 검사

일러스트는 이 프로젝트를 위해 AI로 생성했습니다. 원본을 포함하므로 Godot에서 그대로 가져와 사용할 수 있습니다. 폰트가 프로젝트 안에 있어 사용자 PC의 한글 폰트 설치 여부에 의존하지 않습니다.

## 검증

```sh
# 첫 실행 또는 새 체크아웃: 리소스 가져오기
godot --headless --editor --path . --import --quit

# 실제 Godot 네 프로세스, 로컬 UDP 소켓 필요
python3 tests/run_network.py

# 여섯 화면 생성 및 기본 해상도에서 화면 바깥으로 나가는 요소 검사
godot --headless --path . res://tests/ui_smoke.tscn
```

네트워크 테스트는 테스트 전용 UDP 25489를 사용합니다. 4인 이전 시작 방지, 동시 중복 선택 충돌, 유효하지 않은 선택 요청, 선택 확정·취소, 네 배역의 동기화, 이탈 후 초기화를 검사합니다. 같은 기기에서의 통신 검사이며 실제 외부 인터넷 경로는 별도로 확인해야 합니다.

저장소에는 엔진 캐시 `.godot/`를 포함하지 않습니다. 내보내기 실행 파일을 만들려면 Godot에서 대상 OS용 공식 Export Templates를 설치하고 내보내기를 설정하세요.
